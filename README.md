Excelから読み込んで、聞くだけでスルスル覚えるフラッシュカード
Excel（XLSX / CSV）から単語帳を読み込み、
英語 → 日本語 を自動で読み上げながら、画面にもカード表示する学習ツールです。
やる気が出ない日でも「聞くだけ」で学習できる、ゆるい英語フラッシュカードアプリ。


主な機能
Excel / CSV 読み込み
- 1列目：英語（読み上げは英語ネイティブ音声）
- 2列目：日本語（読み上げは日本語音声）
- Shift-JIS の CSV にも対応（自動で UTF-8 に変換）
- 
自動読み上げ
- 英語 → 日本語の順に読み上げ
- 日本語を読まない設定も可能
- 読み上げ速度を 0.5〜2.0 倍で調整可能
- Web Speech API を使用（ブラウザ標準の音声）
- 
自動ループ再生
- 単語帳の最後まで行ったら自動で最初に戻る
- ループ OFF にすれば1周で停止
- 
フラッシュカード表示
- 現在の単語と意味を大きく表示
- 聞きながら見るだけでも学習できる
- スマホでも見やすい UI
